A free, open source retrospective board for agile and remote teams: create a board, share the link and everyone can add, merge and vote on items live, without any login.
It comes with drag and drop grouping, dot voting and a shared timer, is hosted in Germany and can be self-hosted with a single Docker image.
The code is available on [GitHub](https://github.com/jakob-r/retromode).
